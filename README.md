# Españoladas

> Cuando un mexicano se casa con una española y descubre que "coger el autobús" no significa lo mismo en ambos lados del Atlántico.

**[→ Ver la web en vivo](https://espanoladas.com)**

## ¿Qué es esto?

Un diccionario colaborativo y abierto que compara cómo se dicen las mismas cosas en distintos países hispanohablantes: México, España, Argentina, Colombia, Chile, Cuba, Estados Unidos y el norte de México.

La lista nació de las conversaciones diarias entre un mexicano viviendo en Madrid y su mujer española. Cada malentendido, cada carcajada, cada _"¿¡pero cómo le dicen ustedes?!"_ fue a parar aquí. Ya lleva más de 300 entradas — y sigue creciendo gracias a la comunidad.

## ¿Cómo contribuir?

**La forma más fácil:** entra a la web, haz clic en cualquier celda vacía, escribe la palabra y pulsa Enter. Sin cuenta, sin registro. Tu aportación aparece inmediatamente.

También puedes [abrir un issue](https://github.com/pedro-rtm/espanoladas/issues/new?template=sugerencia.yml) si prefieres.

## Stack

- HTML + CSS + vanilla JS (un solo archivo, sin framework)
- [AG Grid Community](https://www.ag-grid.com/) para la tabla interactiva
- [Supabase](https://supabase.com/) para la base de datos y autenticación
- GitHub Pages para el hosting
