# Contribuir a Españoladas

## La forma más fácil

1. Entra a [la web](https://pedro-rtm.github.io/espanoladas/)
2. Encuentra una celda vacía (aparece como `¿?`)
3. Haz clic, escribe la palabra, pulsa Enter
4. Listo. Tu aportación aparece al instante.

No necesitas cuenta ni registro.

## Reportar un error o sugerir algo

[Abre un issue](https://github.com/pedro-rtm/espanoladas/issues/new?template=sugerencia.yml) describiendo:
- El concepto (ej. "Aguacate")
- El país
- La palabra o expresión correcta
- Si la entrada existente tiene un error, explica cuál

## Código de conducta

Esto es un proyecto divertido sobre las diferencias lingüísticas del español. Mantenlo respetuoso. Las entradas vulgares o groseras están permitidas si son genuinas (el español es así), pero el spam y el vandalismo serán eliminados.
